description: Summarize the current session concisely
---

Review the entire current session and produce a concise, plain-language summary.

Include only:

**Done:** completed work and important outcomes
**Decisions:** key choices or conclusions
**Open:** unresolved issues, blockers, or unanswered questions
**Next:** suggested next steps, if any
**Prompts:** the exact number of user-authored prompts/messages in this session

Use short paragraphs under bold section labels, not hyphen-prefixed bullets. Omit empty sections. Do not invent details or count assistant/tool messages as prompts.
